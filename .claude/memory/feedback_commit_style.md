---
name: Commit message style
description: How to write git commit messages for this project
type: feedback
---

Never use Co-Authored-By in commit messages.

Write short, conventional commit messages: `fix: ...`, `feat: ...`, `chore: ...` etc. One line, concise.

**Why:** User prefers clean, standard commit history without attribution lines.

**How to apply:** Always on every commit in this project.
